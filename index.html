Step 2 — AI Null Imputation (optional)
Groq API Key Free · Ultra-fast inference · Used to intelligently fill missing values
▶
After Gemini extracts your data, Groq analyzes null cells and fills them using median/mean for numbers, mode for categories, interpolation for sequences, and cross-column inference — each with a method label, confidence score, and one-sentence reason. Images are never sent to Groq — only column names and values.
1
Go to Groq Console
Visit console.groq.com — completely free, no payment method needed.
2
Create a free account
Click Sign Up — you can use Google, GitHub, or email. The free tier is generous with no credit card required.
3
Navigate to API Keys
Click API Keys in the left sidebar, or go directly to console.groq.com/keys.
4
Create a new API key
Click Create API Key, give it a name (e.g. parquet-tool), then Submit. Your key starts with gsk_… — copy it immediately, it won't be shown again.
5
Paste & enable the toggle
Paste the key below, then flip the AI Null Imputation toggle on. This tool uses llama-3.3-70b-versatile — Groq's free-tier flagship.
